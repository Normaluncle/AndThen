# AndThen 250 封面 CDN 直链

- `AndThen_250封面直链_大陆CDN.xlsx`：主要使用表，250条。
- `AndThen_250封面直链_大陆CDN.csv`：前端/脚本容易读。
- `AndThen_250封面直链_大陆CDN.json`：可直接导入程序。
- `AndThen_250封面直链_可视化预览.html`：双击打开即可看到250张卡片，图片从远端CDN加载。

## 来源
本批直链使用 `img.cc0.cn` 的图片CDN缩略图地址，源分类页来自 `cc0.cn`。CC0.CN说明其面向国内访问进行了服务器/CDN加速；但任何第三方直链都不能承诺所有运营商、所有时间永久可用。比赛Demo建议可直接用，长期产品建议迁移到自己的OSS/CDN。

## 许可注意
CC0.CN说明网站图片可用于商业/非商业用途，但站点同时聚合部分第三方图库。使用带明显人物、商标、建筑或特殊版权内容时仍应检查肖像权、商标权及原图来源条件。不要暗示图中人物为产品或具体故事背书。

## 标签说明
标签按封面用途进行宽分类与复合绑定；这批主要解决“无原图时快速给卡片匹配低信息密度背景”的场景。
