# AndThen 封面图库 150 清单

这是给「然后呢」项目用的封面图库清单压缩包。

## 包内文件
- AndThen_封面图库150清单.csv
- AndThen_封面图库150清单.json
- 分类汇总.csv
- 使用说明.md

## 说明
1. 总数：150 条。
2. 结构：以「主类 + 复合标签 + 视觉描述」为主，方便你们后端或前端直接做标签匹配。
3. 当前其中 18 条带有实际示例链接（Pexels），可直接先看方向。
4. 其余条目是完整的封面概念位，用于保证你们系统先可落地；后续可继续按 `推荐检索词_EN / 推荐检索词_ZH` 批量补图。
5. 每条都尽量控制为“低信息密度、可盖标题、可复用、多标签绑定”。

## 字段说明
- id：封面编号
- 主类：主类别
- 复合标签：可同时命中多个类别/主题
- 视觉描述：给前端、运营、补图同学看的实际画面描述
- 推荐检索词_EN / 推荐检索词_ZH：后续补图时直接用
- mood：氛围
- people_count：人物数
- scene_type：场景类型
- composition：构图倾向
- overlay_safe：是否适合盖标题
- source_platform：来源平台（已选样张/待补图）
- source_url：如有现成链接会放这里
- status：已选样张 / 概念位

## 使用建议
你们系统可先这样匹配：
1. 先按主类命中；
2. 再按复合标签细化；
3. 如文章无图，则优先选 `overlay_safe=是` 且 `status=已选样张`；
4. 若没有现成图，再按清单中的视觉描述或检索词继续补图。
