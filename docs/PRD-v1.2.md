# 然后呢？PRD v1.2 — 独立网站与作者记忆

状态：实施中。2026-09-13。本文件是 v1.1 的增量实施版本；原始 PDF 与已有业务约束保留。

## 产品目标

读者发现旧内容，点击“然后呢？”，原作者接受回访，一问一答补充近况，编辑并确认一则“后来”，在本站发布，关注者收到站内更新。前端交付功能完整、可继续美化的页面。

## 范围与平台能力

- 发现入口同时包含本站获准展示的内容和知乎官方搜索结果。
- 搜索文本是 api_summary，精选评论是部分评论，均不冒充完整原文或完整评论区。
- 支持读者提交回答/文章链接。只接受准确 URL 匹配；不能读取时保存待补全状态，不抓取、不要求读者复制全文、不使用无关搜索结果。
- OAuth 登录和资料读取按具体接口权限执行。Access Secret 本人全文/评论接口不能套用任意 OAuth 用户身份。
- 作者主页使用可靠链接字段；不得根据昵称猜测身份或合并人物。
- 发布、通知、撤回发生在本站。邀请仅记录人工触达，不新增自动私信或 RPA。
- OAuth 缺少 App ID/App Key 或安全回调联调未通过时明确不可用，不提供虚假登录。

## 采访与作者记忆

采访保持一问一答，最多五个主问题，可跳过、暂停、恢复；输入先保存，再调用模型。使用百炼 qwen3.8-flash，向量模型 qwen3.7-text-embedding，默认 1024 维，每批最多 20 条文本。

memU 固定版本：08e1ed4cdf4c0cb1fe5387e4a532ea588a8cbe46。Python 内部服务存放可重建的 SQLite 索引，PostgreSQL 保存业务授权、原始依据和版本。

| 触发 | 期望行为 |
|---|---|
| 搜索结果出现 | 不批量生成档案 |
| 首次关注或正式回访候选 | 每个来源版本生成一次有限准备材料，归属未核验前按帖子隔离 |
| 作者首次同意 | 核验归属后建立作者记忆，首批最多 20 条许可材料 |
| 重复访问 | 复用现有版本，超过 24 小时后台检查变化 |
| 采访提问 | 每个主问题最多检索一次，最多五条、约两千字；明确拒谈边界始终生效 |
| 暂停 | 保存会话，不重复生成长期记忆 |
| 作者确认新资料 | 按确认版本更新，旧事实修正不得重复并存 |
| 撤销、修改或删除 | 立即停止使用旧资料，清缓存并重建索引；旧任务不能写回 |

记忆只为更好的提问。摘要不得独立充当公开事实证据；每条事实需关联有效来源和逐字依据。不得推测人物性格、收入等缺失资料。

## 页面与验收

发现、内容、关注、通知、作者工作台、采访、草稿、账号与记忆、受保护管理页面均需可实际操作，包含空态/错误/异步状态。禁止仅用 Swagger 替代产品页面。

草稿页面应能主动发起 AI 整理和依据检查。整理以已保存的采访回答为输入，生成未确认的新版本；页面须说明草稿阶段另行修改的文字需要保留。检查只提供规则或模型意见，不能代替作者确认。队列完成但模型输出无效时，应显示未取得可用结果，保留原稿，并允许检查条件后重试。

作者可展开已保存版本引用的依据，分清原内容摘要/片段、本次采访回答和本人修改。私有依据只向该作者开放，缺失或过期明确标示。采访回答可以选择私有或可用于公开草稿；草稿可逐项调整公开范围、移除条目，修改后必须保存并重新确认，不能沿用旧版本的确认。

验收要求：双账号完成关注、接受回访、记忆采访、确认发布、接收更新、撤回；自动化覆盖权限、去重、保存、重启、资料更新和撤销。memU 必须完成真实模型项目级联调，不以服务降级替代成功验收。

## 与 v1.1 的变更

新增官方渠道、读者链接入口、作者记忆生命周期、可美化的功能前端和对应部署。保留身份服务、材料真实性、逐项同意、作者核验、公开投影、发布确认、删除和研究口径。数据库只新增迁移。

详细实时交付状态见 implementation-v1.2.md；本 PRD 描述目标，不代表所有条目已完成。

### 官方候选与登录前准备

发现页同时列出站内公开故事和服务端保存的官方候选摘要。搜索不触发记忆建档；读者首次关注候选后，才登记该来源并后台整理、向量化已有摘要。重复关注同一材料版本复用准备结果。客户端只能提交候选 ID 和关注开关，不能替换官方摘要或指定作者身份。

准备材料按来源及快照保存，不按昵称归并，也不会因为出现一个新昵称就建立作者档案。原作者核验通过并同意相关资料处理后，才允许在作者记忆中复用这些有来源依据的准备材料。取消关注只取消该读者的关注，不撤销其他读者的需求；删除来源使其准备材料失效并排入索引清理。

读者导入的来源可以在原作者核验并同意私有采访后进入人工回访审核，无须先公开原文。运营人员随后创建回访时，应复用数据库中已经核验的作者归属；先建立回访、后核验作者时也应完成相同关联。核验操作按来源串行，不能同时把同一内容核验给两个账号。

摘要继续明确标为摘要；精选评论继续标为精选部分。未取得可信作者主页字段时不猜测链接。关注不等于已联系作者，也不代表已获得公开全文许可。

### 评论同步的本轮实现边界

管理员可通过官方数据页读取凭证账号的本人摘要、全文和评论，并为已登记来源按页同步评论。本站只向知乎读取；没有向知乎回写评论的接口。根评论分页和附带楼中楼分开说明，不能承诺所有子评论均已取得。每次同步最多一页，按 ID 更新，保留官方提供的分页游标；失败不把本页记为成功。首次演示最多缓存 2000 条评论。

普通读者只能在已获准公开的故事中看到本站已同步部分。全文/评论的凭证本人限制继续保留。当前真实账号内容列表为空，不能把契约测试当作已有真实全文/评论的成功验收。

### 提问边界与语义记忆

作者明确拒谈的边界作为独立约束加载，不与“最多五条、约两千字”的相关经历竞争名额。检索不可用时仍使用有效边界。若输入超过整体预算，进入明确的降级状态，不能为凑预算静默丢掉边界。

相同材料版本只复用索引并更新检查时间；再次进入作者工作台时，超过 24 小时才请求后台刷新。授权过期、撤销、确认版本失效或资料保留期清理后，旧内容不得继续用于提问。

同一作者（登录前为同一来源）的记忆建档、刷新和清理任务，在有效执行租约期间串行运行，覆盖多个 worker 和不同材料版本。记忆建档与采访共用模型并发上限；其他作者的索引清理不占模型名额。租约过期后允许恢复执行，索引版本和租约检查继续阻止旧任务写回。

重复刷新按作者及版本去重。失败后主动刷新显示“处理中”并清除旧错误提示；已有可用记忆的例行刷新保留可用状态。该限制是并发控制，不代表已对记忆调用实现每日费用额度。

### 作者可见的资料清单

资料与记忆页展示已核验属于当前作者的资料标题、材料范围和处理状态：已有可用记忆、缺少采访/模型处理同意、尚未取得材料、超出首批 20 条范围、暂无可用记忆。最多展示最近 50 条，超出时明确提示未列全。清单不披露其他作者或尚未核验归属的私有资料，也不把无记忆一律解释为模型失败。
