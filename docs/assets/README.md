# README 素材清单

先提供封面就够了，其他素材可后补。图片不要带真实用户隐私或密钥。

| 素材 | 建议比例/尺寸 | 内容 | 建议文件名 |
|---|---|---|---|
| 首屏横幅 | 3:1，1800×600 | 从旧回答走向新生活的时间感；蓝白或暖白，留出标题空间，文字可后加 | hero.webp |
| 产品流程截图 | 16:9，1600×900 | 真实 Demo 的发现、采访、后来阅读，三张分别导出 | discover.webp / interview.webp / followup.webp |
| 仓库社交预览 | 2:1，1280×640 | 项目名、短标语、简洁主视觉 | social-preview.png |
| 可选图标 | 1:1，512×512，透明背景 | 用“？”与时间/对话表达项目，不冒用知乎官方标识 | logo.png |

封面可用生成图片；功能截图应来自真实页面，避免把概念图当作已实现界面。每张尽量控制在1MB以内，动画可后续提供一个短GIF或视频链接。收到素材后放在本目录，README用相对路径引用；社交预览需另到仓库设置上传。
